# ДомЭксперт — Frontend

Премиальный SPA-сайт для эксперта по недвижимости. Покупка на котловане, строительство под ключ, обучение бизнесу.

## Стек

- **React 19** + **Vite 7**
- **Tailwind CSS v4** (через `@tailwindcss/vite`)
- **Lucide React** — иконки

## Быстрый старт

```bash
npm install
npm run dev
```

Открой [http://localhost:5173](http://localhost:5173)

## Сборка для продакшна

```bash
npm run build
npm run preview
```

## Структура проекта

```
src/
  App.jsx       — весь UI: навигация, роутинг, компоненты, моки
  main.jsx      — точка входа
  index.css     — подключение Tailwind
```

## Страницы

| Страница       | Описание                                                                 |
|----------------|--------------------------------------------------------------------------|
| **Главная**    | Hero, статистика, блок «О нас», последние 3 объекта, CTA                 |
| **Каталог**    | Сетка карточек с фильтром по статусу и поиском                           |
| **Обучение**   | Лендинг курса: для кого, программа (6 модулей), что входит               |
| **Кабинет**    | Форма добавления объекта + переключатель Админ / Ученик (mock-авторизация)|

## Mock-авторизация

В личном кабинете переключатель **Админ / Ученик** демонстрирует две роли:

- **Админ** — видит все объекты, раздел управления доступом учеников
- **Ученик** — видит только свои объекты и статус своего доступа

Данные хранятся в состоянии React и сбрасываются при перезагрузке.

## Деплой на GitHub Pages

```bash
# Установить gh-pages
npm install -D gh-pages

# Добавить в package.json:
# "homepage": "https://<USERNAME>.github.io/<REPO>",
# "predeploy": "npm run build",
# "deploy": "gh-pages -d dist"

npm run deploy
```

Также добавь в `vite.config.js`:

```js
export default defineConfig({
  base: '/<REPO>/',
  plugins: [react(), tailwindcss()],
})
```
